# 👋 Hey
I’m Pdawg, a 17 year old developer interested in emulation, low-level systems, and figuring out how computers actually work.

I spend most of my time building things from scratch and trying to make software fast, clean, and accurate. C# is my primary language, though I also work with C/C++ and other languages like JavaScript, HTML, CSS, Python, and even Assembly (ARM32/Z80, less-so x86) when a project calls for them.

## What I'm working on
- **Trident:** A Game Boy Advance emulator written in C#, focused on performance and clean architecture and semi-decent accuracy.
- **Kasasagi:** A work-in-progress low-level Nintendo 3DS emulator written in C# once again targeting speed and clean architecture.
- **Ontos:** A collection of reusable processor instruction decoders (i.e. ARM32) built with C# source generation.

## Other projects
- **BadBuilder:** A well-known, respected, and automated tool for creating BadUpdate/ABadAvatar USB drives for the Xbox 360.
- **Ether:** A portable, deterministic C++ ray tracer and ray marcher.
- **Katera:** A C# source generator for deterministic bitfield layouts.

## What I enjoy
Anything that involves understanding what's happening under the hood: CPU architectures, emulations, reverse engineering, compiler/runtime behavior, performance optimization, you name it. It's great.
Most of my projects are independent experiments, so some are more actively developed than others.
